CSS Box Model

Every element is a box made of 4 layers

The 4 Layers

Margin (outside space)
Border
Padding (inside space)
Content

content-box vs border-box

content-box

width: 300px padding adds ON TOP actual size = 340px

border-box

width: 300px padding included INSIDE actual size = 300px

Margin Collapse

When two vertical margins meet, they collapse into one. The larger margin wins — they do NOT add together.

margin-bottom: 40px
margin-top: 20px

Gap between them = 40px, not 60px
